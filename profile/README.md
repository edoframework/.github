## Taihei Framework

*Prosperity through clarity.* 天下泰平

Open-source Scala 3 libraries from [Innovenso](https://innovenso.com), for the JVM and Scala.js,
released to Maven Central under `dev.taihei` and licensed under the Apache License 2.0.

| Library | What it does |
|---|---|
| [i18n](https://github.com/taiheiframework/i18n) | Languages, translatable messages, ICU MessageFormat 2.0 and locale-aware formatting |
| [lorem](https://github.com/taiheiframework/lorem) | Fake data and Lorem Ipsum for tests, seed data and mock-ups |

More libraries will follow. See [taihei.dev](https://taihei.dev),
[how to contribute](https://github.com/taiheiframework/.github/blob/main/CONTRIBUTING.md) and the
[security policy](https://github.com/taiheiframework/.github/blob/main/SECURITY.md).
