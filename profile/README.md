## Edo Framework

*Prosperity through clarity.* 天下泰平

Open-source Scala 3 libraries from [Innovenso](https://innovenso.com), for the JVM and Scala.js,
released to Maven Central under `com.edoframework` and licensed under the Apache License 2.0.

| Library | What it does |
|---|---|
| [i18n](https://github.com/edoframework/i18n) | Languages, translatable messages, ICU MessageFormat 2.0 and locale-aware formatting |

More libraries will follow. See [edoframework.com](https://edoframework.com),
[how to contribute](https://github.com/edoframework/.github/blob/main/CONTRIBUTING.md) and the
[security policy](https://github.com/edoframework/.github/blob/main/SECURITY.md).
